# MostafaMohammed - Professional Barista Portfolio

A dynamic, full-stack portfolio application designed to showcase the expertise, career journey, and achievements of a professional barista. Built with modern web technologies, this application features a responsive public interface and a comprehensive admin dashboard for content management.

## ✨ Site Features

### 🌐 Public Interface
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop devices.
- **Dynamic Hero Section:** Engaging introduction with animated statistics (Years Experience, Cups Served, etc.).
- **Skills Showcase:** Visual representation of professional skills with proficiency levels.
- **Career Timeline:** Interactive timeline displaying work history and achievements.
- **Certificates Gallery:** Grid view of professional certifications.
- **Video Gallery:** Showcase of barista skills and tutorials via video content.
- **Contact System:** Integrated contact form with real-time validation and email notifications.

### 🛡️ Admin Dashboard
A secure, password-protected area for managing all website content.

- **Dashboard Overview:** Quick insights into site activity and content statistics.
- **Message Center:** 
  - View all contact form submissions.
  - Filter messages by status (New, Read, Replied).
  - Search messages by name, email, or content.
  - **Direct Reply:** Send email replies directly from the dashboard using the integrated email system.
- **Content Management Modules:**
  - **Skills:** Add, edit, and delete professional skills.
  - **Career:** Manage career timeline entries.
  - **Certificates:** Upload and manage certificate images and details.
  - **Courses:** Manage training courses offered.
  - **Gallery:** Upload and organize photo gallery images.
  - **Videos:** Manage video links and previews.
- **Settings:** Update global site metadata and profile information.
